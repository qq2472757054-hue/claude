# 开发决策记录

开发文档没写清楚的地方，按“对不懂技术的使用者最简单”的原则决定，记录如下。

## 结构与运行
1. **仓库根目录即 `coolplay-mixer/`**，目录结构按开发文档第 9 节；另加 `app/state.py`（全局上下文）、`app/ffrun.py`（ffmpeg 调用、可取消）、`app/imageio.py`、`app/render/engine.py`（单比例渲染）、`app/render/imgfx.py`（Pillow 工具）、`app/jobs/runner.py`（执行单个任务）、`app/ui/page_music.py`（配乐登记页，文档 6.6 要求界面登记）。
2. **settings.toml 放在程序目录**（便携包整体拷走设置也在）；可用环境变量 `COOLPLAY_SETTINGS` 指定（测试用）。
3. **首次选择素材库**：网页里无法弹出系统文件夹对话框，所以“设置”页提供输入框 + “选择文件夹…”按钮（工具运行在本机，由本机进程弹出 tkinter 对话框；不可用时直接填路径）。切换素材库无需重启。
4. Gradio 只监听 `127.0.0.1`；端口被占用时自动顺延。

## 素材库
5. **原始备份路径**：`原始备份/<SHA-256 前 12 位>/<原文件名>`，避免同名覆盖。
6. **城市/景点**：`待使用/<城市>/<景点>/…`，取第一层子文件夹为景点。
7. 扫描时已登记且大小未变的文件跳过哈希计算（大量素材时启动快）。用户手动挪动的文件按哈希识别并更新位置。
8. 内容完全相同的配乐只登记一次。
9. 新增素材状态“丢失”：文件和记录都找不到时标记，原始备份仍在。

## 分析
10. **画质阈值**（320px 宽灰度图）：平均亮度 < 30 过暗、> 235 过曝；拉普拉斯方差 < 25 过糊；5 帧平均帧差 < 0.4 几乎静止。阈值在 `analysis/quality.py` 顶部。人工可“恢复”或“标记为低质量”。
11. 切镜用 PySceneDetect 的 PyAV 后端（OpenCV 在 Windows 上读不了中文路径），失败时整段视频作为一个片段。抽帧统一走 ffmpeg 管道，同样为了中文路径。
12. 语音识别：先做 Silero VAD（不需要下载模型），有人声才识别；音频解码改用 ffmpeg（faster-whisper 自带的解码与新版 PyAV 不兼容）。模型未就绪时其他分析照常进行，识别排队等待。
13. 人工修改的识别文本保存在 `transcript.edited_text_json`，生成时优先使用。

## 生成
14. **一个任务 = 一条视频的全部比例**：多比例共用同一组素材（同一条内容的不同比例），每个比例各自一个输出、各自审核。素材在所有比例都成功后才移动。
15. **批次内素材**：同一批次中，被前面任务移到 `已使用/` 的素材在本批次内仍可被选（受重合率控制），否则 20 段素材生成 5 条时后几条会因“素材不足”失败。重合率定义为 |A∩B| / min(|A|,|B|)。
16. 挑选顺序：严格匹配 → 放宽景点 → 超过重合率上限（提示）→ 放宽类型（提示）→ 失败。认为“用错类型”比“和同批次稍有重复”更糟。
17. **时长**：段落时长先随机取，再整体缩放到目标 ±10%；保留原声的段落按语句定长不参与缩放；片尾品牌卡 2.5 秒计入总时长。素材太短达不到时给出提示而不是失败。
18. 转场时长自动限制为最短片段的 40%。“硬切”和“无”都使用直接拼接。
19. 渲染：每段先编码成统一规格的中间文件（1080 宽、30fps），最后一次合成转场、logo、字幕、音轨。图片在 Pillow 中先做填充（含 EXIF 方向、heic），再用 zoompan 做推拉平移。
20. 音频：配乐循环截取 → 淡入 1 秒 / 淡出 2 秒 → 人声期间侧链压缩 → 两遍 loudnorm（线性模式达不到目标时改用动态模式），目标 −14 LUFS。没有可商用配乐时仍可生成（静音或仅原声），并在审核界面提示。
21. 硬件编码依次尝试 NVENC / QSV / AMF（Windows）或 VideoToolbox（macOS），用 0.5 秒测试编码确认可用；任何一步失败自动回退 libx264。最终输出限制最高码率 12 Mbps，便于上传平台。
22. **输出目录**：`输出/待审核/` 中每条输出就是一个以文件命名规则命名的文件夹（内容与发布包相同：video.mp4、封面、srt、caption.txt、info.json），审核通过只需整体移动到 `已审核/`。先写到 `.名称.part` 临时文件夹，完成后改名，避免出现半成品。
23. 渲染失败时临时目录改名为 `临时/失败_job_<id>` 保留 7 天；取消和程序被强制关闭时清理。
24. 程序被强制关闭后：中断的任务标为失败（可重试），素材不动；若输出已经写好但素材还没移动，启动时补做素材流转。

## 字幕与封面
25. 换行用“宽度单位”（英文 1、中文 2；竖屏 32 单位 ≈ 32 个英文字符或 16 个汉字），同时用实际字体测量像素宽度，二者都满足才放一行；每屏最多两行，超出按字数比例分屏。中英双行模式下每种语言每屏一行。
26. 字幕安全区：竖屏底部 15% + 20px、右侧 12%，左侧 6%。开场标题居中，行动号召在底部安全区之上。
27. “字幕语言 = 无”时不烧录任何文字（包括开场标题），SRT 为空。
28. 字体：内置 Noto Sans SC（Regular/Bold，SIL OFL 1.1，含拉丁字母），首次启动复制到 `字体/`，渲染时用 `fontsdir` 指定（相对路径，避开 Windows 盘符冒号的转义问题）。
29. 封面从第一个段落和评分最高的两个片段附近取帧，按清晰度和亮度打分；审核页换帧是从成片中取帧。

## 文案（DeepSeek）
30. 只有模板勾选“用 DeepSeek 自动生成”且设置中已启用时才生成文案；字幕翻译只要启用了 DeepSeek 就会自动进行。失败一律回退到模板文字，不影响生成。
31. 没有 DeepSeek 时，发布文案 = 开场标题 + 行动号召，话题标签 = 城市英文名 + #ChinaTravel 等通用标签 + 品牌名。

## 已知限制
- Windows 便携包脚本（`tools/build_portable.py`）尚未在真实 Windows 机器上验证。
- 开发环境（4 核云主机、无显卡）上，30 秒 1080×1920 视频渲染约 55–75 秒。
