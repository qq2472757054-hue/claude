# 酷玩假期 · 旅游短视频混剪工具

把重庆、成都、张家界的景点、美食、游客、导游、酒店素材，**批量**剪成 TikTok / YouTube Shorts / Facebook Reels 短视频，
同时出封面和图文海报。所有内容先人工审核，再由人工发布。

- 全部在本机运行，素材不会上传到任何地方。
- 只有两处会联网：① 第一次下载语音识别模型；② 可选的 DeepSeek 文案（默认关闭）。

---

## 一、启动

| 电脑 | 操作 |
|---|---|
| Windows 10/11 | 双击 **`启动.bat`** |
| macOS | 双击 **`启动.command`**（第一次会自动准备运行环境，需要联网几分钟） |

启动后浏览器会自动打开工具页面（地址类似 `http://127.0.0.1:7860`）。
**黑色命令行窗口不要关**，关掉它就退出了工具。

### 更新到最新版
如果当初是用 Git 下载的程序（`git clone`），以后有新版本时双击 **`更新.bat`** 即可，素材库和设置不受影响。

## 二、第一次使用

1. 打开“**设置**”页 → ① 素材库位置：点“选择文件夹…”选一个空文件夹（例如 `D:\酷玩素材库`），点“**使用这个位置**”。
   工具会自动建好下面这些文件夹：

   ```
   酷玩素材库/
   ├── 待使用/重庆、成都、张家界   ← 新素材放这里
   ├── 已使用/                      ← 工具自动维护，不用管
   ├── 原始备份/                    ← 每个素材导入时自动备份一份，永不自动删除
   ├── 配乐/轻快、抒情、动感、城市夜景 ← 背景音乐，子文件夹名就是风格
   ├── 品牌/   字体/   模板/
   ├── 输出/待审核、已审核、已退回
   └── 数据/   临时/   日志/
   ```
2. 在“设置”页填写**品牌信息**（品牌名、WhatsApp、LINE、网址），上传 logo。片尾卡和海报都会用到。
3. 语音识别：点“**下载模型**”。国内网络建议先在“模型下载镜像地址”填 `https://hf-mirror.com`，保存设置后再下载。
   下载不了也可以手动放：按页面上的说明下载 4 个文件，放到 `数据/models/faster-whisper-small/`，再点“我已手动放好模型，重新检测”。
4. （可选）DeepSeek：填 API Key、勾选“启用”，点“测试连接”。

## 三、日常流程

```
补素材 → 定主题 → 工具生成 → 人工审核 → 少量发布（人工） → 看反馈
```

### 1. 放素材、补标签（“素材库”页）
- 把视频/图片拷进 `待使用/<城市>/`。可以再建子文件夹，例如 `待使用/张家界/天门山/`，子文件夹名会自动当成“景点”。
- 支持：mp4 / mov / mkv / avi / m4v；jpg / jpeg / png / heic / webp。
- 点“**扫描新素材**”（启动时也会自动扫描）。重复的文件只提示，不会重复入库。
- 工具会在后台自动分析：切镜头、判断画质（过暗/过糊/几乎不动会标成“低质量”，默认不用）、做缩略图、识别导游说的话。可随时“暂停/继续分析”。
- 在“登记表”里给每个素材填 **类型**（必填）和 **能否公开使用**。
  **只有“能否公开使用 = 是”的素材才会被用到视频里**，页面顶部会用红字提示还有多少个“未确认”。
- 素材多的时候可以“导出登记表 Excel”，在 Excel 里批量填好再“导入 Excel”。
- 点缩略图可看素材详情：片段列表（可以手动恢复被判为低质量的片段）、识别出的文字（可以直接改，改后的文字优先用作字幕）、这个素材被用在了哪些视频里。

### 2. 配乐（“配乐”页）
把音乐放进 `配乐/<风格>/`，点“扫描配乐”，填写来源、授权说明。**只有“能否商用 = 是”的曲目才会被自动选用。**

### 3. 模板（“模板”页）
模板决定一条视频长什么样：时长、比例、段落顺序（每段用什么类型的素材、几段、每段几秒、是否保留原声）、字幕语言、文字、转场、配乐风格、logo 和片尾卡。
内置 3 个：**张家界 48 小时**、**成都美食速览**、**重庆夜景**，可以直接用，也可以“复制为新模板”后修改。

### 4. 生成（“生成”页）
选模板 → 城市 → 比例 → 条数 → “开始生成”。右边会提示素材够不够。
任务一个一个排队执行，可以取消、失败可以重试。生成好的视频在 `输出/待审核/`。

### 5. 审核（“审核”页）
点列表中的一条：看视频、封面、字幕、发布文案、用了哪些素材。
- **通过**：移到 `输出/已审核/`，文件夹里就是发布包：

  ```
  video.mp4  cover_9x16.jpg  cover_16x9.jpg  subtitles.srt  caption.txt（文案+话题，直接复制） info.json
  ```
- **退回**：写原因；勾选“素材退回待使用”会把这条用过的素材放回 `待使用/`。
- **编辑后重新生成**：改开场标题、说明文字、语音字幕，或勾选要换掉的片段，其余素材不变。
- **换封面帧**：拖动时间条选一帧，重新生成封面。

### 6. 海报（“海报”页）
选 1–4 张图（上传或从素材库选），填标题、副标题、要点，选版式（单图大标题 / 双图对比 / 四宫格）和尺寸（4:5、1:1），生成后也进 `输出/待审核/`。

## 四、素材会被怎么移动？（重要）
- 导入时先备份到 `原始备份/`，**备份永远不会自动删除**。
- 视频**生成成功并通过检查**之后，用过的素材才会从 `待使用/` 移到 `已使用/`（保持城市/子文件夹结构）。
- 生成失败或取消：**素材原地不动**。
- 工具每次启动都会检查记录和实际文件是否一致，以实际文件为准自动修正。

## 五、常见问题
| 现象 | 处理 |
|---|---|
| 生成失败：“××城市××类型素材不足，还差 N 段” | 补充该类型素材，或在模板里减少段数 / 改类型 |
| 视频里没有背景音乐 | “配乐”页里该风格下没有“能否商用=是”的曲目 |
| 字幕提示“字幕未翻译” | 导游说中文、字幕设为英文时需要开启 DeepSeek 翻译，或在审核页手动改字幕后重新生成 |
| 语音识别一直没开始 | “设置”页下载/放置模型 |
| 其他错误 | “设置”页 → “打开日志文件夹”，把当天的日志发给技术同事 |

## 开发者说明
- Python 3.11+，`pip install -r requirements-dev.txt`，`python -m app.main`；测试：`python -m pytest`。
- Windows 便携包：在 Windows 上运行 `python tools/build_portable.py --zip`（自动下载 Python 嵌入版、依赖、FFmpeg）。
- 演示素材：`python tools/make_demo_library.py <空文件夹>` 生成一套合成测试素材。
- 设计取舍记录在 `docs/DECISIONS.md`。字体为 Noto Sans SC（SIL OFL 1.1，见 `assets/fonts/OFL.txt`）。
